### 💡 关于我与研发理念

- 🦀 **系统级与终端生态 (TUI)**：重度 Rustacean，深度探索 **Ratatui** 终端图形界面，打造常驻内存极小、响应达毫秒级的极客级控制中枢。
- 💙 **跨平台现代应用 (GUI)**：基于 **Flutter & Dart** 设计工业美学软件，兼具流畅直观的操作交互与跨操作系统生态能力。
- 🐧 **极客开发环境**：主力工作流基于 **Arch Linux (Wayland / Hyprland)**，推崇键盘流高效交互与纯粹的系统掌控力。
