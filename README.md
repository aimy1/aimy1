### 💡 关于我与开发理念

- 🦀 **Rust & 终端生态 (TUI)**：重度性能与体积强迫症，不把内存压到 **~5MB**、启动压到 **<10ms** 就会浑身难受。
- 💙 **Flutter 跨平台开发 (GUI)**：追求克制优雅的现代工业美学。界面做得好看是理所当然的，才不需要特意夸奖。
- 🐧 **Linux 键盘流工作流**：全套 Arch Linux (Wayland / Hyprland) 环境，坚持效率第一，概不妥协。
